# 2026-10-17 追加修复记录

## 范围

本轮在 UI checkpoint `70c539b` 之后，按优先级处理上一轮带读确认的问题：

1. 敏感文件重命名/复制后的 Diff 泄漏。
2. 快照的 `target` 身份不一致，导致干净工作区回退和提交区间无法多轮追问。
3. 切换提交/区间时旧会话未失效，自由追问可能回答旧目标。
4. 按仓库恢复会话时丢失聚焦文件，追问返回 409。
5. 快照过期后的恢复路径、重复复制监听、提交图标、扫描根容错、提交元数据脱敏和主题首屏闪烁。

## 修复内容

### P0 敏感路径

- `lib/diff.js` 对 `path` 和 `oldPath` 同时做敏感分类；重命名 `.env`、`proxy-key`、私钥等到普通文件名不再绕过过滤。
- `lib/git.js` 的排除提示会同时指出新路径和来源路径。
- 回归覆盖工作区 Diff、历史提交和直接 patch 解析三种路径。

### P1/P2 快照与选择生命周期

- 快照保存请求目标 `requestedTarget`，追问比较同一字段；不再把解析后的 SHA 当作验证目标。
- 快照事件返回 `requestedTarget` 与实际 `resolvedTarget`，客户端分别用于选择校验和证据说明。
- 客户端对话绑定当前目标；切换目标、切换聚焦文件会清空会话并删除该仓库的已保存会话。
- 按仓库恢复会话时同时保存并恢复 `target` 与 `focusFile`；聚焦文件已不在当前 Diff 时清空会话，避免复用旧快照。
- 快照过期/回收返回 409 时，客户端丢弃快照并提示；下一次精读或提问会重新建立快照。

### P3 工程与体验

- 移除代码块复制按钮的重复监听，只保留统一事件委托。
- 提交列表补一次 `lucide.createIcons()`，工作区图标正常渲染。
- 单个不可读/非目录扫描根不再让整个仓库列表 500，而是跳过并记录警告。
- `/api/repos` 与提交接口统一对已配置凭据脱敏，覆盖提交标题和仓库摘要。
- 新增 `public/theme-init.js`，在首屏 CSS 前应用已保存主题，减少浅色模式闪烁。
- 移除 marked 18 已不支持的 `highlight` 配置；高亮继续由 `postProcessArticle` 完成。
- Keeper 未知配额使用弱化颜色；导出文件名清理仓库名中的路径/控制字符。
- 更新 README 的快照、选择、敏感路径和脱敏说明。

## 保留边界

- 本地 token 仍不是多用户权限系统；同一系统用户的本机进程不受隔离。
- 快照仍是内存态，重启或 30 分钟过期后需要重建。
- 工作区捕获是“读取后复核”，不是文件系统事务；本机并发写入仍可能竞争。
- 证据仍按预算截断，不能把回答视为完整仓库审查。
